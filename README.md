# Advanced-Excel
Automated weekly travel operations dashboard built in Excel using normalized data and dynamic conditional formatting.
Travel Operations Dashboard (Excel)
Overview

This project demonstrates an automated travel visibility dashboard built using Excel. The dashboard uses normalized trip data to generate a weekly Gantt-style timeline view for operational planning.

Problem

Stakeholders lacked clear weekly visibility into employee travel schedules, creating coordination inefficiencies.

Approach

Structured trip data in a normalized format (one row per trip).

Used dynamic conditional formatting with COUNTIFS logic to automatically generate weekly timeline bars.

Designed the layout to scale across employees and date ranges.

Features

Weekly Gantt-style travel timeline

Automated overlap detection

Scalable data structure

Clean executive-friendly layout

Tools Used

Excel Online

Conditional Formatting

COUNTIFS

Dynamic filtering
